# إلي وعليّ — نسخة الويب للآيفون

افتح [التطبيق](https://muatasemm-cmd.github.io/eli-walay-web/) في Safari على الآيفون. من زر المشاركة اختر **إضافة إلى الشاشة الرئيسية**. نسخة الويب لا تحتاج إلى تجديد توقيع Apple.

## نقل بيانات نسخة الآيفون الأصلية

1. افتح التطبيق الأصلي قبل انتهاء توقيعه، ثم **الإعدادات ← حفظ نسخة من البيانات**، واحفظ ملف JSON في «الملفات» أو iCloud Drive.
2. افتح نسخة الويب واضغط **استيراد بيانات الآيفون** في الشاشة الأولى، أو **الإعدادات ← استيراد JSON**.
3. راجع عدد الأشخاص والحركات والمواعيد بعد الاستيراد، ثم احفظ نسخة جديدة من الويب في iCloud Drive.

تقبل نسخة الويب ملف `eli-walay-native-backup` من تطبيق SwiftUI، بما فيه الأشخاص والحركات والمواعيد والإعدادات. لا تنقل إعداد Face ID أو تنبيهات النظام؛ Face ID والتنبيهات المحلية الأصلية غير متاحة في صفحة GitHub Pages. البيانات تحفظ داخل Safari على الجهاز نفسه، ولا تُزامن تلقائيًا بين أجهزة مختلفة. لا تحذف التطبيق الأصلي قبل التأكد من ظهور البيانات في الويب ووجود ملف النسخة الاحتياطية.
